## Fork notes

This fork grows A Dark Room into a city and empire builder: the village becomes a town, then a city, then an empire, while keeping the original's spare tone. Upstream files stay under MPL-2.0; new test tooling is MIT. Google Analytics is removed.

Run the game with `npm start` (http://localhost:8080). Run the tests with:

```
npm ci
npx playwright install chromium
npm test
```

`npm test` runs headless Chromium smoke tests (fresh load, scripted play) and checks that a v1.3 save (`tests/fixtures/v1.3-village.json`) still loads intact. CI runs the same on every push and pull request.
